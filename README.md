# Zafir Perfumaria · Landing page

Landing page desenvolvida para a **Zafir**, loja de perfumes árabes originais em Manaus (AM). Projeto feito para um cliente: o site apresenta o catálogo da loja e leva o visitante a fechar o pedido pelo WhatsApp.

## ✨ Funcionalidades

- **Catálogo com filtros** por família olfativa (doce, cítrico, amadeirado, floral...) e por público (masculino/feminino)
- **Busca** de perfume por nome ou marca
- **Quiz "Descubra o seu perfume"**: 5 perguntas que recomendam fragrâncias de acordo com o gosto do visitante
- **Carrossel** de destaques e seção "Um para ele, um para ela"
- **Pedido direto pelo WhatsApp** a partir de cada produto
- **Tema claro/escuro** com a preferência salva no navegador
- **Responsivo**, com cuidados de acessibilidade (link "pular para o conteúdo") e SEO (meta description)

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (sem frameworks)
- Deploy na Vercel

## 📁 Estrutura

```
├── index.html      # estrutura da página
├── styles.css      # estilos e temas claro/escuro
├── script.js       # catálogo, filtros, busca, quiz e carrossel
└── assets/img/     # imagens dos produtos
```

## ▶️ Como rodar localmente

Não precisa instalar nada. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/Vitorzz1212/Zafir-site.git
cd Zafir-site
```
